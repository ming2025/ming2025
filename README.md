## 我关注的方向

- **AI 工作流：** 把复杂目标拆成清楚的步骤、输入、输出与验收条件。
- **人机协作：** 让 AI 在共同目标下分担任务，并用实际体验检验效果。
- **可验证的迭代：** 区分事实与假设，保留实验记录、失败与回滚方式。
