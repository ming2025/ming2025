# 你好，我是 Ming

我在探索 **AI 工作流与人机协作**：把想法做成可以运行、解释和验证的应用。

目前主要推进两个项目，从可视化任务拆解到实时游戏合作，观察 AI 怎样更有效地参与复杂工作。

## 正在做的项目

### 坦克大战 × AI

人类操作 P1，规则与策略库驱动 P2；本地大模型在赛后复盘，策略调整通过对照测试后才用于下一局。

[项目仓库](https://github.com/ming2025/BattleCity-AI-Coop) · [交互介绍与运行机制](https://ming2025.github.io/BattleCity-AI-Coop/) · [运行说明](https://github.com/ming2025/BattleCity-AI-Coop/blob/main/QUICKSTART.md)

**当前状态：** Windows 可运行研究原型，已有真人试玩与验证记录；整局合作收益、多步回防和主动清敌仍在持续研究。

### VibeFlow

将工作流画布与 Prompt IDE 放在一起，用节点、提示词模板和独立版本记录、比较 AI 协作过程，支持人工分步推进与关联同步。

[在线使用](https://ming2025.github.io/VibeFlow/) · [项目仓库与使用说明](https://github.com/ming2025/VibeFlow) · [V3.4.0 下载](https://github.com/ming2025/VibeFlow/releases/tag/v3.4.0)

**当前状态：** V3.4.0 已发布，修复保存切换、即时导出、撤销重做与 Markdown 分支往返问题；15 项回归检查通过，依赖已内置，并提供迁移说明与旧版归档。记录保存在当前浏览器，工具不自动调用模型。

## 我关注的方向

- **AI 工作流：** 把复杂目标拆成清楚的步骤、输入、输出与验收条件。
- **人机协作：** 让 AI 在共同目标下分担任务，并用实际体验检验效果。
- **可验证的迭代：** 区分事实与假设，保留实验记录、失败与回滚方式。
